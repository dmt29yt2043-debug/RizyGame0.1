# РИЗИ: Побег из Идеалити

Мини-бродилка в духе Little Big Adventure по книге Резеды Снигирь «Побег из Идеалити».
Один уровень — вся арка книги: от кануна Нового Блока в домике с оранжереей до побега
за биокупол и первого шага по живой земле Люмениры.

## Как играть

Любой статический сервер из корня папки, например:

```bash
python3 -m http.server 5199
```

и открыть http://localhost:5199

## Управление

- Стрелки / WASD — идти, SHIFT — бежать
- E / Enter — говорить, действовать, листать диалоги
- ПРОБЕЛ — импульс кристального сердца (открывается по сюжету):
  оглушает кубитов, рассеивает иллюзии, показывает ритм Кристов, будит древнее
- F2 — режим отладки (границы проходимости, координаты по клику)

## Сюжет уровня

1. **Дом Ризи** — ёлка, чердак, книга Хранителей, пробуждение кристального сердца.
   Утром кубиты запечатывают маму в капсулу sleepy-mode.
2. **Улица Идеалити** — Му-Хрю в бегах, лампьютер, отключение кнопки на виске,
   старик в огромных очках, патрули кубитов.
3. **Туннели** — Спрут, парализующее поле Кристов, спящий Гаргонт (не бегать!).
4. **Ангар «Антарес-15»** — иллюзии Закулисья (найди предмет не на своём месте)
   и пробуждение корабля Анибус тремя импульсами сердца.
5. **Леса Люмениры** — стеклянная бабочка и крючок на продолжение.

## Технически

- Чистый JS + Canvas, без зависимостей (`index.html`, `js/game.js`, `js/data.js`)
- Пре-рендеренные фоны в стиле войлочной stop-motion диорамы (AI, по референсам мира RIZYLAND)
- Спрайты Ризи, Му-Хрю и мамы вырезаны из официальных мастер-листов персонажей
- Здоровье = энергия сердца: тишина лечит, страх и стычки истощают
